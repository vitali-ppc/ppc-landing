## 1. Аватары (для кого главная)

Полная аудитория — в `BRAND-BRIEF.md §2`. Якорим главную по трём входным эмоциям SMB-владельца (спенд Google Ads $3–50K/мес, тех. уровень 3.5, founder-led self-serve):

1. **Тонущий DIY-владелец (~50%)** — паника, «ROAS упал / pMax жжёт бюджет». JTBD: остановить кровотечение, понять почему. → главную открывает **pain-mirror**.
2. **Тул-шоппер (~30%, высший intent)** — гонял Optmyzr/Madgicx, дорого и сам верчу. JTBD: тул, который **действует**, а не советует, за SMB-цену. → **live agent-feed** + **экономический клин**.
3. **Обжёгшийся на агентстве (~20%)** — платил $1.5–3K, был слепым. JTBD: уволить агентство, но **видеть** работу. → слоган «Your PPC agency. In a cabinet.» + видимый лог.

**Анти-аватары** (должны отваливаться): новички уровня 1–2 / спенд <$1K; PPC-профи уровня 5 (хотят raw control); enterprise >$50K (нужны seats/SLA); Meta/TikTok-first (продукт Google-Ads-only).

## 2. Концепция: «покажи работу, а не обещай результат»

Бренд B6 = «AI делает работу агентства, но ты ВИДИШЬ каждый ход». Главная делает эту прозрачность **видимой на первом экране** через live-feed агентов, а не рассказывает про продукт.

Несущие приёмы (каждый закрывает аватара):
- **Pain-mirror** в первой строке (mono, amber) — ловит панику аватара 1 до слогана.
- **Live agent-feed** справа — лог-строки Buzz/Aegis/Echo со статусами `applied / held / sent`. Отвечает аватару 2 на «действует или советует». Это отстройка от дашбордов-рекомендаций (Optmyzr/Madgicx).
- **Экономический клин** на первом экране — `agency $2–5K` (зачёркнут) → `tools $499` → `Kampaio $99–399` (акцент). Самый сильный аргумент не закопан в /pricing.
- **Уверенный beta-фрейм** — «Founding access · first 30 accounts» вместо «Limited beta» (не сигналит «сыро» аватару 2).

## 3. Тема и цвет

**Светлая тема** (по решению владельца — dark отклонён). Все цвета — CSS-переменные в `<style>`-блоке внутри `HomeContent.tsx`, префикс `.kx`.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#F6F8FB` | фон страницы (холодный off-white) |
| `--surface` | `#FFFFFF` | карточки, feed |
| `--surface-2` | `#EEF2F8` | вложенные блоки, navbar tint |
| `--text` | `#0D1320` | основной текст (cool ink) |
| `--muted` | `#5B6979` | вторичный текст |
| `--muted-2` | `#37445A` | body/усиленный вторичный |
| `--border` | `#DCE3ED` | границы |
| `--accent` | `#0A7C8C` | **deep teal-cyan** — ссылки, fills, акценты |
| `--accent-2` | `#0A8294` | конец градиента кнопок |
| `--teal` | `#0B7A68` | success-чипы, live-индикатор |
| `--warn` | `#B45309` | pain-line, hold-чип, SOON |
| `--danger` | `#DC2626` | зачёркнутая цена, ошибки |

**⚠️ Про акцент:** исходный неоновый cyan `#00FFE7` **нечитаем на белом** (контраст ~1.2). Заменён на глубокий teal-cyan `#0A7C8C` (WCAG AA на белом) — сохраняет «cyan-ДНК» бренда. Текст на кнопках — **белый** (`#FFFFFF`), не тёмный.

## 4. Типографика

- System-stack (`system-ui, -apple-system, "Segoe UI"`) — без кастомных шрифтов на главной.
- **Mono** (`ui-monospace, SF Mono…`) — для ВСЕХ цифр и данных (цены, CPA/ROAS, agent-feed, клин, eyebrow). Моноширинное = «данные/аналитик», совпадает с voice бренда (≈0.47 sentiment, факт+интерпретация).
- H1 — `clamp(40px,6vw,62px)`, градиент `ink → teal`, fluid под все экраны.

## 5. Компоненты (всё в `HomeContent.tsx`, классы `kx-*`)

| Блок | Решение |
|---|---|
| TopBar | sticky + blur, вордмарк `● kampaio`, nav-анкоры (скрыты `<640`), Sign in + Start free |
| Hero | асимметрия `1.05fr / .95fr`: слева eyebrow→pain→H1→sub→CTA→клин; справа live agent-feed |
| Live feed | mono лог Buzz/Aegis/Echo, чипы applied/held/sent, `live`-pulse, fade-in строк |
| Эконом-клин | 3 ячейки, agency зачёркнут (danger), Kampaio акцентирован |
| How it works | bento 3 шага + лестница автономии `L1 / L2 / L3` |
| Meet your agency | 7 агентов, 2 LIVE / 5 SOON, монолайн-иконки |
| Pricing | 3 тарифа ($99/$199/$399), L2 «Most popular», контраст с агентством |
| CTA | «Ready to fire the agency?» + WaitlistForm (логика к `/api/waitlist/signup` сохранена) |
| Footer | вордмарк + ссылки |

Состояния: hover/focus-visible на всех интерактивах, `prefers-reduced-motion` отключает анимации. Адаптив: `960px` (планшет, hero/bento стекаются), `640px` (телефон, nav-линки/клин в колонку).

## 6. Иконки (без emoji — правило)

**Emoji запрещены** — детские 🐝🛡️🐻 удешевляли дизайн. Вместо них — единый набор **монолайн-SVG** (`stroke=currentColor`, 1.8, viewBox 24), по функции агента:

| Агент | Иконка id | Глиф |
|---|---|---|
| Buzz (Bidding) | `bid` | trending-up |
| Aegis (Risk) | `shield` | щит |
| Maximus (Orchestrator) | `stack` | слои |
| Vox (Strategy) | `target` | мишень |
| Mira (Creative) | `spark` | звезда/искра |
| Sage (Research) | `search` | лупа |
| Echo (Reporting) | `chart` | бар-чарт |

Иконки в teal-плитках (`rgba(10,124,140,.10)` фон, accent-цвет). Маскоты как бренд живут в **именах и копирайте**, не в emoji.

## 7. Что НЕ делаем (анти-паттерны)

- ❌ **Emoji** в продуктовом UI — только монолайн-иконки.
- ❌ **Неоновый cyan `#00FFE7` на светлом** — нечитаем; только `#0A7C8C`.
- ❌ **Тёмная тема** на главной (отклонена владельцем).
- ❌ **Русский копирайт** на англоязычной главной (ЦА — US/global; был дефект, исправлен).
- ❌ Хардкод цветов — всё через `--*` токены.
- ❌ Generic AI-лук (центр + 3 карточки) — асимметрия, bento, mono-данные.
